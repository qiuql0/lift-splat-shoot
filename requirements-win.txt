# Lift-Splat-Shoot — Windows 依赖锁定清单
#
# 适用环境：Windows x64 + Python 3.10 + NVIDIA GPU（CUDA 11.8）
# 本清单由已验证可用的环境导出，可复现 src/ 全部功能。
#
# 安装顺序不能颠倒：
#
#   1) 先装 CUDA 版 PyTorch
#      注意：Windows 上 PyPI 默认源给的是 CPU 版，必须走 PyTorch 官方索引。
#
#      pip install torch==2.1.2+cu118 torchvision==0.16.2+cu118 \
#          --index-url https://download.pytorch.org/whl/cu118
#
#      国内加速（实测约 6.5 MB/s，官方源在国内仅约 1 MB/s）：
#      https://mirror.sjtu.edu.cn/pytorch-wheels/cu118/
#      将其中的 torch-2.1.2%2Bcu118-cp310-cp310-win_amd64.whl 与
#      torchvision-0.16.2%2Bcu118-cp310-cp310-win_amd64.whl 下载后本地安装：
#      pip install --no-deps <两个 .whl 的本地路径>
#
#   2) 再装其余依赖
#      pip install -r requirements-win.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
#
# 注意：本文件不包含 torch / torchvision，请按第 1 步单独安装。
