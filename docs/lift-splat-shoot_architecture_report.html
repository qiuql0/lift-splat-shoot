项目概述

这是一个极简的参考实现：没有 requirements.txt、没有 setup.py、没有测试套件。整个数据流都收在 src/ 下的 5 个模块里，入口统一由 main.py 通过 fire 分发。

核心思路是用一个可微的"隐式反投影"替代显式深度估计：网络为每个相机、每个像素预测一个离散深度分布（41 个 bin），把 64 维上下文特征与深度分布做外积，得到每台相机的特征视锥；所有视锥的 3D 点被投影到统一的 BEV 栅格并做求和池化；最后用一个截断 ResNet18 头输出 BEV 车辆分割。

▸ Lift（提升）

每台相机独立预测 D=41 个深度 bin 的 softmax 分布，与 C=64 维图像上下文做外积 → 特征视锥 B·N×D×8×22×64。

▸ Splat（泼溅）

用相机内外参把视锥点映射到自车坐标系，离散化到 200×200、0.5 m 的 BEV 栅格，QuickCumsum 求和池化。

▸ Shoot（投射）

论文里的 "shoot" 指把模板轨迹投射进 BEV 代价图做运动规划；本仓库只实现了 BEV 车辆分割（outC=1），不包含 shoot / 规划部分。

把图像与后处理仿射矩阵 post_rot/post_trans 一起更新：resize → crop → flip → rotate，逐步左乘对应的 3×3 齐次变换。在 get_geometry 中会被逆变换抵消掉，所以增强不影响 3D 投影。

Lift · CamEncode 特征视锥构建

CamEncode 内部逐层结构（自下而上）。依赖 EfficientNet 私有成员 _blocks/_swish/_bn0/_conv_stem/_global_params，因此 efficientnet_pytorch 锁 0.7.0。
LIFT CamEncode
条目内容
入口类CamEncode(D, C, downsample) — models.py:37
输入x: B·N×3×128×352
输出B×N×D×8×22×C（D=41, C=64），即特征视锥
损失无独立损失，随整个网络端到端训练
关键参数D=41（来自 dbound）、C=64（camC）、downsample=16
特殊机制 ① 手动抽取 EfficientNet 的 reduction_4 / reduction_5 特征图，up1 融合（320+112 → 512）
② depthnet 是 1×1 卷积，输出 D+C=105 通道
③ lift 操作 = depth.unsqueeze(1) * context.unsqueeze(2)（外积），把每个像素的 64 维特征"铺"到 41 个深度 bin 上

Splat · 几何映射 + 体素池化

voxel_pooling 内部步骤（自下而上）。QuickCumsum 是自定义 autograd Function，等价于 cumsum_trick 的可微版本。
SPLAT get_geometry + voxel_pooling

get_geometry()（models.py:166）

对 create_frustum() 构建的 D×8×22×3 射线网格：先减去 post_trans、乘 post_rots 的逆（抵消图像增强），再补齐次坐标做透视除法，然后乘 rots @ intrins.inverse()，最后加 trans，得到自车坐标系下的 3D 点 B×N×D×8×22×3。

条目内容
入口LiftSplatShoot.get_geometry / voxel_pooling — models.py:166 / 200
输入geom: B×N×41×8×22×3；x: B×N×41×8×22×64
输出B×64×200×200（折叠 Z 后）
关键参数dx 格子尺寸、bx 首格中心、nx 格子数（都由 gen_dx_bx 从 grid_conf 推导）
特殊机制 ① 越界点过滤：0 ≤ idx < nx 的 mask
② 线性 rank 编码 x*nx1*nx2*B + y*nx2*B + z*B + batch，argsort 让同一体素的点连续

gen_dx_bx(xbound, ybound, zbound) — 网格配置的唯一真源

把 [min, max, step] 三元组转成：格子尺寸 dx、首格中心 bx = min + step/2、格子数 nx = (max−min)/step。models.py 和 data.py 中所有 BEV 网格相关代码都走这个函数，确保网络与 GT 的栅格定义一致。

QuickCumsum — 可微的分段求和池化

前向：cumsum → 只保留每个 rank 段的最后一个元素 → 差分还原段和。反向：back = cumsum(kept); back[kept] -= 1; val = gradx[back]，把梯度广播回段内所有点。cumsum_trick 功能相同但走 autograd 原生路径，用于 cumsum_check 做数值一致性验证。

SimpleLoss / get_batch_iou

SimpleLoss 是带 pos_weight 的 BCEWithLogitsLoss，训练时 pos_weight=2.13 用于补偿车辆像素稀少。get_batch_iou 接收未过 sigmoid 的 logits（内部用 > 0 阈值），返回 (intersect, union, IoU)。

已知陷阱

问题说明
CPU 模式train 里 SimpleLoss(...).cuda(gpuid)、eval_model_iou 里 SimpleLoss(1.0).cuda(gpuid) —— 即便上方做了 CPU 设备选择，gpuid < 0 依然会报错。
评估 loss ≠ 训练 losseval_model_iou 把 pos_weight 硬编码为 1.0，而训练用 2.13。评估打印的 loss 不是训练目标。
checkpoint 与配置强耦合torch.load 恢复裸 state_dict，grid_conf/final_dim/dbound/Ncams 必须与训练时一致，否则形状/几何会静默偏移。
BEV 轴序转置voxel_pooling 填的是 (Z, X, Y)；绘图代码用 [..., Y, X] 并调用 .T；binimgs 通过交换角点对齐。新增 BEV 代码前先确认约定。
增强按相机独立sample_augmentation() 在 get_image_data 的相机循环内部调用，同一帧的各相机有各自的随机变换。几何不受影响，但别假设共享。
efficientnet 版本锁efficientnet_pytorch==0.7.0 必须锁定，因为 get_eff_depth 直接访问私有成员。
dataroot 拼接compile_data 传的是 os.path.join(dataroot, version)，所以 dataroot 本身不含 version 子目录。
