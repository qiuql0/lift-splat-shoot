## 视锥

视锥是一个(41,8,22,3)的shape。41是深度，8是128//16，22是352//16，3是坐标。

### 获取三维点 get_geometry

先撤销图像增强的仿射变换，包括旋转和平移，回到(900, 1600)。

公式：d(u, v, 1) = kP_cam。P_cam=KP_ego。最后将所有视锥点都变为ego坐标系下的points，俯视图是锥形。

### 广播机制

两个张量做运算时，**从最后一个维度开始向前逐一比对**，每个维度需满足以下**任意一条**：

1. **两个维度相等** → 直接对齐
2. **其中一个维度为 1** → 该张量会沿着这个维度"拉伸"（广播）到另一个的大小
3. **其中一个维度不存在**（等价于 1）→ 缺失维度自动补 1 参与运算
4. matmul运输，最后两个维度对齐，然后开始向前逐一对比。


### loss
- BCE = Binary Cross Entrony，二元交叉熵，它用于二分类任务。
L = −[ y·log(p) + (1 − y)·log(1 − p) ]
因为 y 只能取 0 或 1，两项中总有一项被消掉。
BCEWithLogitsLoss，名字里的 “WithLogits” 是重点：它把 sigmoid 和 BCE 合一步，输入要求是原始 logit，即未经过sigmoid 的分数。为什么不用自己先 sigmoid 算 BCE？因为这样一来 p 会逼近 0 或 1，log(p) 就变成 log(0) = −inf，数值溢出。- 
- pos_weight 是什么？
  它是给“正样本那一项”乘的系数，只影响 y = 1 
  L = −[ pos_weight · y·log(p)  +  (1 − y)·log(1 − p) ]
         └──── 只有这一项被放大 ────┘   └─ 负样本不变 ─┘




### 问题

**为什么自动驾驶要用 BEV 表示？和直接在图像上做检测相比，好处是什么？**
答：自动驾驶要做的决策都发生在地面上，BEV（鸟瞰图）就是"地面坐标系下的地图"。用 BEV 表示，可以把多个相机、多种传感器和下游规划统一到同一个坐标系里。
