# LSS

## 数据部分

### 数据获取：图像、雷达和标签

训练时选取5个相机，test时用6个相机，一帧有6个相机的图像。

图像增强有缩放，裁剪，翻转，旋转，可以用一个二维仿射变换表示。最后处理完都是(128, 352)的。

激光雷达点云移除太近的点(2.2米)，因为可能是车子本身的杂点。需要多帧的点，一帧的点太少了。把其他帧的点云移到当前坐标系下。

bev网格：x和y轴都是-50到+50的坐标值。格子大小0.5，所以格子坐标都是0到200，初值都是0。将标签在自车坐标系下的坐标，转为bev网格的坐标，命中的格子为1。bev网格图像，xy坐标还要翻转一下。



## 视锥

视锥是一个(41,8,22,3)的shape。41是深度，8是128//16，22是352//16，3是坐标。

### 获取三维点 get_geometry

先撤销图像增强的仿射变换，包括旋转和平移，回到(900, 1600)。

公式：d(u, v, 1) = kP_cam。P_cam=KP_ego。最后将所有视锥点都变为ego坐标系下的points，俯视图是锥形。

### 广播机制

两个张量做运算时，**从最后一个维度开始向前逐一比对**，每个维度需满足以下**任意一条**：

1. **两个维度相等** → 直接对齐
2. **其中一个维度为 1** → 该张量会沿着这个维度"拉伸"（广播）到另一个的大小
3. **其中一个维度不存在**（等价于 1）→ 缺失维度自动补 1 参与运算
4. matmul运输，最后两个维度对齐，然后开始向前逐一对比。
